DuelPlay — исправление кодировки уведомления об обновлении (исправленный скрипт)

Причина:
В предыдущем патче русские подписи в components/Common/LivePlatformSync.tsx были записаны в виде mojibake, а статический тест проверял повреждённую строку, поэтому проходил несмотря на ошибку текста.

Применение:
1. Распакуйте этот архив в корень C:\Users\User\Desktop\duelplay-app.
2. Откройте PowerShell в корне проекта.
3. Выполните:
   powershell -ExecutionPolicy Bypass -File .\Fix-DuelPlay-Invite-Refresh-Encoding.ps1
4. Затем по отдельности выполните:
   node scripts/test-admin-auth-flow.mjs
   npm run build

Исправлена совместимость вызова Regex в PowerShell: уникальное совпадение заменяется через Match.Result, после предварительной проверки точного количества совпадений. Скрипт проверяет ожидаемый вариант файлов, перед записью выполняет все проверки в памяти и создаёт резервную копию двух файлов во временной папке Windows. Он не выполняет git commit, push и не меняет production.
