# DuelPlay test accounts

В проект добавлены два тестовых игрока:

- `TEST_PLAYER_1`
- `TEST_PLAYER_2`

Они помечаются в базе как `isTestAccount=true` и не попадают в публичный рейтинг.

## Включение

1. Применить миграции Prisma:
   `npx prisma migrate deploy`
2. Добавить в переменные окружения длинный секрет:
   `DUELPLAY_TEST_ACCOUNTS_SECRET=...`
3. Открыть `/test-login` и ввести этот секрет.
4. Выбрать `TEST_PLAYER_1` или `TEST_PLAYER_2`.

При первом входе тестовые аккаунты создаются автоматически с балансом `$1000` каждый. Повторный вход не сбрасывает их текущий баланс.

Также можно создать их заранее командой:
`npm run test:setup`

Тестовый вход намеренно не добавлен в обычную страницу Steam-авторизации.
