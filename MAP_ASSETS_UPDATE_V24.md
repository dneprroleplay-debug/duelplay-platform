# DuelPlay V24 — map and case visuals

Changes in this release:

1. Removed the homepage popular-map `<Games>` section. Map selection remains part of the match creation flow.
2. Replaced the 10 DuelPlay map preview assets with the user-supplied labeled images.
3. Added the 3 user-supplied case cover images for Starter Case, Neon Duel Case, and Premium Arsenal.
4. Added the 6 user-supplied case item images and wired them into the case cards, roulette, win screen, API case payloads, and inventory item creation.
5. Added a regression check for all 19 supplied visual assets and homepage map-section removal.

No CS2 timing, betting, matchmaking, server-manager, ADMIN/SUPERADMIN, or duel-result logic was changed by this update.
